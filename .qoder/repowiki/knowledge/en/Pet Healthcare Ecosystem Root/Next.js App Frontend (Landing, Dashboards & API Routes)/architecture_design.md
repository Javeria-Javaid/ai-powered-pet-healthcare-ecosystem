The module is organized by Next.js App Router into three cooperating layers under `app/`: server-side Route Handlers in `api/**` expose endpoints for auth, pets, clinics, vet, appointments, conversations, reminders, and AI chat; client pages in top-level folders (`dashboard`, `clinic/dashboard`, `vet/dashboard`) render role-specific dashboards; and presentational components in `components/` are composed by the root layout and landing page. Cross-cutting concerns — site metadata, HTML shell, and global Tailwind theme — live at the module root so every child route shares the same context without imports. The landing page (`page.tsx`) is the entry point: it calls `/api/auth/me` to resolve identity and redirects to the appropriate dashboard based on role, while also loading Google Identity Services and invoking `/api/auth/google/config` + `/api/auth/google/callback` for OAuth.
