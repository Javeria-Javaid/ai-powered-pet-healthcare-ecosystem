# Project Decision Log: Pet Healthcare Ecosystem

This document serves as the official design decision log for the Pet Healthcare Ecosystem, establishing the technical foundations and MVP scope agreed upon before system architecture design.

---

## 1. Core Technical Decisions

| Decision Area | Selected Option | Rationale / Implementation Details |
| :--- | :--- | :--- |
| **Authentication** | Database-backed custom session management | Uses opaque cryptographically random tokens (Node.js crypto) stored as SHA-256 hashes in the Prisma `Session` model. Sessions are mapped via a secure HttpOnly SameSite cookie. Password hashing targets Argon2id (pending verification). Authentication is kept strictly server-side and separate from authorization, avoiding JWTs and insecure client/request header injection. |
| **Database** | PostgreSQL | Robust support for relations, complex schemas, transaction isolation, and JSON/audit logging capabilities. |
| **ORM** | Prisma | Provides type safety, auto-generated migrations, and cleaner TypeScript integration for Next.js API routes. |
| **File Storage** | Alibaba Cloud OSS | Highly durable object storage ideal for pet photos, prescriptions, and health documents. |
| **OSS Visibility** | Private | Restricts public access to sensitive medical and personal document files to maintain strong data privacy. |
| **File Access** | Short-lived Presigned URLs | Secure, time-limited download URLs (Signature V4) generated by Next.js API routes to authorized users/vets. |
| **Vet ↔ Clinic Relationship** | Many-to-Many capable association | Modeled via `VetClinicAssociation` join table, allowing veterinarians to practice at multiple clinics. |
| **Vet ↔ Pet Access** | Appointment/Consent-based | Vets receive limited access only when an appointment is booked and confirmed by the owner. Access is tied to the relationship/appointment. |
| **Medical Records Update** | Auditable/Versioned revisions | No destructive `UPDATE` statements. Corrections and updates append as addenda or new revisions referencing the original record. |
| **AI Platform** | Qwen via Alibaba Cloud | Leveraging Alibaba Cloud Model Studio for AI assistant queries, health summaries, and insights. |
| **AI MVP Scope** | Assistant + Health Summary | Priorities are a context-aware AI Health Assistant and a structured Medical History Summarizer. |
| **AI Context Generation** | Relevant-Context Retrieval | Retrieves relevant database records dynamically matching the query context instead of a simple "last N records" limit. |
| **AI Triage** | Limited / Deferred | Deferred for the initial MVP to prevent medical liability risks and complex edge cases. |
| **OCR / Document AI** | Deferred | Avoids high complexity of parsing diverse document templates for the hackathon MVP. |
| **Notifications** | In-App first | Simple, local, state-driven notifications stored in the DB and rendered in the UI. |
| **SMS / Email Alerts** | Deferred | Scheduled for post-MVP to minimize cloud costs and third-party SMS/SMTP integration overhead. |
| **Security & Compliance** | Strong security/privacy principles | Focuses on encryption in transit, secure credentials, private files, audit logs, and data minimization rather than pursuing formal HIPAA/GDPR certifications. |
| **UI Priority** | Basic Functional UI | Prioritizes feature depth and correct business logic first, followed by clean styling. |
| **Development Style** | Feature-by-feature | Iterative development following the defined roadmap phase dependencies. |

## 4. Consent-Based Vet Access Details

When an appointment is booked and confirmed, the veterinarian is temporarily granted access to a subset of the pet's healthcare data:
1.  **Pet Basic Profile:** Name, species, breed, gender, age, weight, allergies.
2.  **Relevant Medical History:** Dynamic retrieval of records matching symptoms or previous major conditions.
3.  **Vaccinations:** Chronological vaccine log to verify preventative status.
4.  **Active Medications:** Active list to check drug compatibility.
5.  **Consultation Records:** The log of appointments and records associated with this specific clinic/veterinarian.
