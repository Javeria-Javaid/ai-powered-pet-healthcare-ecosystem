Single-file Prisma schema (`schema.prisma`) declares a PostgreSQL datasource with `prisma-client-js` generation. The model centers on `User` (with `UserRole` enum: PET_OWNER, VETERINARIAN, CLINIC_ADMIN, PLATFORM_ADMIN) and branches into domain entities: `Pet`, `Veterinarian`, `Clinic`, `VetClinicAssociation` (many-to-many bridge with `AssociationStatus`), `MedicalRecord` + versioned `MedicalRecordVersion`, plus supporting models for `Appointment`, `Prescription`, `Vaccination`, `Medication`, `Allergy`, `HealthCondition`, `HealthMetric`, `Document`, `Notification`, `Reminder`, `AIConversation`/`AIMessage`, `AuditLog`, and `Session`. Relationships use explicit named relations (e.g. `VetUser`, `Verifier`, `AuditUser`, `ClinicAdmins`) and cascade/set-null delete rules. Migration history lives under `migrations/` as timestamped folders managed by Prisma Migrate, with a `migration_lock.toml` pinning provider state. `seed.js` bootstraps sample data using `@prisma/client` with a custom `PrismaPg` adapter over `pg.Pool`, supports both plain `DATABASE_URL` and Prisma's `prisma+postgres://` API key format, hashes passwords with argon2, and uses idempotent `upsert` calls keyed by stable placeholder UUIDs.
