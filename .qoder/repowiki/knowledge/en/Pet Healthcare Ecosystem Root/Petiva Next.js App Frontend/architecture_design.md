The app is organized by the Next.js App Router into three cooperating layers under `app/`: (1) `api/**` exposes server-side Route Handlers for auth (`auth/*`), pets, clinics, vet, appointments, and AI chat endpoints; (2) top-level folders `dashboard`, `clinic/dashboard`, and `vet/dashboard` render role-specific pages via Next.js routing; (3) `components/` holds reusable presentational React sections composed in the root layout and landing page. Cross-cutting concerns — global Tailwind theme in `globals.css`, site metadata and HTML shell in `layout.tsx`, and the public landing page in `page.tsx` — are centralized at the module root so every child route shares the same shell and styling context without importing them individually.
