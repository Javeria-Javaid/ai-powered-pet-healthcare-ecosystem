Three files form the application shell under the Next.js App Router: `layout.tsx` declares root `Metadata` (title/description) and renders `<html>`/`<body>` with Tailwind utility classes, importing `globals.css` for theme variables; `page.tsx` is a `'use client'` component that composes the public landing by stacking child components (`Navbar`, `Hero`, `AboutSection`, `CommunitiesSection`, `HowItWorks`, `CTASection`, `Footer`) plus an `AuthModal` and `ChatWidget`. Authentication state and Google Identity Services SDK initialization live in this page — it calls `/api/auth/me` on mount to redirect authenticated users to role-based dashboards (`/vet/dashboard`, `/clinic/dashboard`, `/dashboard`) and posts credentials to `/api/auth/login` or `/api/auth/register`. The module depends only on sibling `./components/*` and Next.js APIs; no server-side data fetching occurs here.
